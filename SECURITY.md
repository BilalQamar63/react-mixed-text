# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(Security tab → "Report a vulnerability") on this repository. Do not open a public issue.

Include the package version, a minimal reproduction and the impact you expect.

## Scope

Relevant reports include ways to make `text`, `size`, `palette` or `fonts` values inject markup or
script, escape the generated `<style>` element, or add CSS declarations that were not requested.

## Supported versions

Only the latest released minor version receives security fixes.
