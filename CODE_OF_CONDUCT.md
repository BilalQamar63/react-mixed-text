# Code of Conduct

We want this project to be a welcoming, harassment-free space for everyone, regardless of
experience, background or identity.

## Expected behaviour

- Be respectful and constructive; critique code and ideas, not people.
- Assume good intent and ask clarifying questions.
- Accept feedback gracefully and give it kindly.

## Unacceptable behaviour

- Harassment, discrimination, personal attacks or insults.
- Sexualised language or imagery, unwelcome attention, or stalking.
- Publishing others' private information.
- Anything that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may edit, remove or reject comments, commits, issues and contributions that violate
this code, and may temporarily or permanently ban contributors who do. To report a problem, use
GitHub's "Report content" feature or contact the maintainers privately through the repository's
Security tab.

This code is adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org).
